**Every close says what is still outstanding**, on an `**Outstanding:**` line in the close's own `--comment` or else the issue's newest comment: the bare word `none`, or `#N (what is left)` items each citing an OPEN issue other than this one. The `guard-issue-close` core and `resolve-ticket.js` (mantahostels#185, #984) refuse anything else. `--reason "not planned"` is exempt. A close through the GitHub UI or `gh api --method PATCH` is not seen, and a `--comment` holding a `$` or backtick expansion is not judged: the guard allows that close and records it unchecked (#990).
