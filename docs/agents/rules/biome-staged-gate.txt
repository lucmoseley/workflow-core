THE PRE-COMMIT BIOME GATE READS ONLY THIS COMMIT'S OWN STAGED PATHS.

An unformatted file the commit does not carry does not block you
(mantahostels#179). Blocked by an unformatted hunk you are not committing yet?
Commit the rest with `commit-paths.js --patch`, which the gate judges as
committed (#2429).

ONE ROUTE IT DOES NOT COVER: repo-wide drift arriving without a commit. After a
Biome version bump, run `biome migrate --write` before a repo-wide
`npx @biomejs/biome check .`.

A LINKED WORKTREE ESCAPES THE MAIN CHECKOUT'S BRANCH CHECK, BUT NOT THE
GATES: it runs the same gates on the same staged paths (mantahostels#344).
