A TOUCHED AREA ABOVE OWES THE ESCALATED TIER, AT ANY SIZE AND IN ANY FILE TYPE: the two axes plus the focused run below. Mission-critical, judged against the touched areas' examples: A change on a sensitive path that alters an access rule or a money calculation itself — who may read or write what, an amount, a redemption state. Touching a file on that path is not enough, and size has no part in it. State `mission-critical: yes|no, because …` before dispatch; a yes names the rule or calculation.
