A PUSH TO `landing` WARNS UNLESS FULL OR ADMISSIBLE `npm run test` GREENS
COVER EVERY COMMIT IT SENDS BETWEEN THEM (mantahostels#2207, #814); no full run is owed:
the lander runs the full suite before `main` moves.

ADMISSIBLE: the bare default against merge-base(HEAD, origin/landing),
`--changed` and its ref, or `--retest <tests>`, over a read graph that renders
(mantahostels#2031, mantahostels#2146, #998); a doc read via an imported HELPER
is selected by nothing (mantahostels#2131). Marker keyed to HEAD at run END
and to the tree it read (#189) — "attested by tree". Each changed file
must lie in some holding run's diff (ADR-0009), and each test reading it hold
in a green. Otherwise `{command:push_check}` names what no green
covers: run its `--retest` command, or the narrowed default.

`npm run test:py` answers for a Python range (mantahostels#1256). Never blocks
(mantahostels#908); fires in a worktree too.
