**`waiting:external` marks an issue whose action has been taken and now sits with someone outside the project** — an affiliate application submitted, an email sent to a party who has not replied. It says nothing about disposition or provenance, so an issue carries it *alongside* its `takes:` and `kind:` values, never instead of one: mantahostels#85 (no working channel to an outside partner) would be `takes:human` **and** `waiting:external` at once.

**The value set is closed at one value.** No `waiting:internal`, no `waiting:founder`, no severity suffix. mantahostels#101 (what defines urgency) ruled out a graded scale, since a graded scale rots.

**Producer: whoever hands the work off, at the moment it is sent** — the founder, or a session that sent the thing itself or has the founder's word that it was sent (#869). No script guesses the label: mantahostels#136 (nothing asks a mid-session issue for its labels) bars a script from guessing a routing value, and mantahostels#101 bars `pick-next.js` from writing at all. The one script that writes it, `scripts/park-blocked.sh <issue> waiting:external "<why>"`, applies the value its calling session names. It comes off by hand when the reply lands.

**Consumer: `scripts/pick-next.js`.** It reads how long the wait has run from the GitHub timeline's `labeled` event — never a date written into the body, which nothing updates when the wait resets — shows the elapsed days in a WAIT column, and **raises the issue's rank once the wait reaches 7 days**, longest wait first. A waiting issue always stays in the shortlist, and one under 7 days ranks exactly as it would with no label.

**Marking an issue "waiting" so the shortlist sinks it makes a stall quieter the longer it runs** — the failure mantahostels#85 already suffered — its request sat "pending" for over five weeks before anyone noticed. Ruled at mantahostels#243 (should a `waiting:external` label exist for work already handed off), built at mantahostels#259 (create `waiting:external` and give it a reader).

**7 days is the earliest point the evidence puts an action at** — chase again, from mantahostels#956's wait-threshold research. The threshold sits at the *first* action the research names rather than its later ones — switch channel at 21 days, treat the counterparty as non-responsive at 45 — because escalating is a prompt to look, not the action itself, and rank goes on climbing with age past 7 anyway.
