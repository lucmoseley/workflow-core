A WHOLE-FILE RESTORE THROWS AWAY EVERY UNCOMMITTED EDIT IN THE FILE, NOT ONLY
THE ONE YOU MEANT. This command puts a whole file back over one holding uncommitted
changes — a `git restore`, a `git checkout -- <path>`, or a `cp` or `mv` onto
it.

- Reverse one change — a mutation test's break, a probe, a wrong edit — with
  the inverse targeted edit, never a whole-file restore. For a whole-file
  rewrite use a throwaway worktree.
- Discard edits by naming their paths: `git restore -- <paths>`, and only
  where every change in them is one to discard.
- Never `cp` a file over one holding uncommitted edits: it writes back an
  older snapshot.

What a restore already discarded is in no commit: where it held an edit you
meant to keep, say so in your reply rather than rewriting it from memory.
