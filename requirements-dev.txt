# Python dependencies for the data-pipeline scripts and their tests.
#
# The Node side of this repo is the product; these two scripts are the one-off
# evidence pipeline behind the partner analysis, and they are not part of the
# Next.js build. Nothing here is installed by `npm install`.
#
#   python3 -m pip install -r requirements-dev.txt
#   python3 -m pytest
#
# Every version below is an exact `==` pin, so an advisory scan reads the versions
# this project installs rather than the newest published release. It pins these five
# and no more: their own dependencies still float, so this is not a full lockfile and
# the transitive tree is still scanned at latest-release. Pins live here rather than
# in a uv.lock or a constraints file because the supply-chain auditor reads neither
# on this machine (mantahostels#930). Bump a pin and reinstall in the same step —
# scripts/test_requirements_pinned.py fails when the two disagree.

pytest==9.1.1

# `npm run test:py` passes -n 2, so this is required, not optional: without it
# pytest exits on an unrecognised argument. Two workers, not `auto` — on this
# machine a worker per core would fight the parallel Claude sessions for the
# 8 GB cap.
#
# This is a LOCAL win only, measured 13 August 2026: 53.4s -> 23.6s here, but
# 111s -> 103s on a GitHub runner, which is ~7%: the CI job barely moves. Two
# vCPU do not scale this FP-heavy bootstrap. Kept because the suite is run
# before every push by hand and halving that is worth having; do not re-argue it
# as a CI saving.
#
# Cutting the CI job took the work itself getting cheaper, at mantahostels#314: vectorising
# the Spearman bootstrap took the suite to 14.0s serial and 7.3s here, and the
# CI job from 127s to 30s. Removing work transfers to a runner; spreading it
# over vCPU there are only two of does not.
pytest-xdist==3.8.0

# Already required at import time by scripts/collect-evidence.py, which reads the
# master sheet, and therefore needed to load that module in a test. Recorded here
# because it was previously an undeclared assumption about the machine.
openpyxl==3.1.5

# Imported by scripts/evidence_audit_stats.py: numpy runs the seeded bootstrap
# resampling, scipy.stats supplies the pre-registered tests (Spearman,
# Mann-Whitney, Kruskal-Wallis). Both were undeclared machine assumptions too.
# 2.4.6 rather than 2.4.0: PyPI has yanked 2.4.0 for a backward-compatibility bug,
# and pip serves a yanked release only to an exact pin (mantahostels#930).
numpy==2.4.6
scipy==1.16.3

# The Python linter, adopted at mantahostels#1135. Config, the rule set and why it is not
# wider: ruff.toml, which owns all of that. Run it with `npm run check:py`;
# .husky/pre-commit runs it on the commit's own staged .py paths and
# ci.yml's python job runs it over the repo.
#
# 0.16.4 is what mantahostels#1135 measured every candidate rule set against. It ships a
# prebuilt aarch64 wheel, so there is no Rust toolchain to install here.
ruff==0.16.4
