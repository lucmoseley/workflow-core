# v1.3.5

## What changed

`init-adopter.js` appends a marked block to `.gitignore` ignoring
`.claude/tmp/` and `/private/`, and the skeleton commit carries it (#737).

`gh pr create` and a push of any branch but `main` or `spike/*` are refused
(#764). A `git reset` naming a commit other than `HEAD` in the shared tree,
and a `git update-ref`, `git branch -f`/`-D`/`-m` or `git checkout -B` that
moves `main`, are refused, forward as well as backwards; move `main` forward
with `git merge --ff-only` (#765). A session
that ends with its own commits unpushed is told which (#766).
