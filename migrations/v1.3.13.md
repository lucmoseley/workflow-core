# v1.3.13

## What changed

The code-standards base your reviews read has changed (#1281): §N2 no longer
asks a test header for a filename, neither the test's own nor its subject's
(#1279). A test header gives one line on what the test pins, why it is built
the way it is, what breaking it costs, and the ticket. A test header that
names itself is still allowed.

`npm run test:py` through the core's `run-pytest.js` now runs from a plugin
install (#1285). It used to stop before collecting a test, with `No module
named 'pytest_pass_plugin'`, because the plugin module ships beside the
wrapper and only your `scripts/` was on PYTHONPATH. A green run now leaves the
pre-push marker, so `push-check.js` counts a Python change covered.
