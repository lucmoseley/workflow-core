# v1.3.2

## What changed

The issue gate refuses a new `wayfinder:map` issue while the repo has an open
map whose Destination still reads `Not named yet — the first session grills
it`, naming the map to fill instead (#717). A spec or brief may now be filed
under a wayfinder map (#714).

`init-adopter.js` writes a complete day-one config: `--corpus` takes the extra
trackers and writes the full list, own tracker first; test, lint and
typecheck commands are inferred from the repo; `gh`'s default repo is set to
origin; and with no `--modules` a re-run keeps the modules
`.claude/workflow-core.json` declares (#715, #716). `.claude/workflow-core.md`
gains a "Switching a module on" section, and a re-run keeps the plugin's
release pin (#730, #731).
