# v1.2.0

## What changed

The plugin now ships the suite's green-run recorders — the two vitest
reporters and the tree-watch `globalSetup` — and `scripts/lib/resolve-core.js`
gains a script form, `node scripts/lib/resolve-core.js <core script> [args]`,
which runs a core script such as `scripts/run-vitest.js`. Together they let a
repo with the `suites` module on record a green run from the plugin, so its
pushes stop warning. docs/agents/helper-surface.md §Running the suite through
the core has the config block and the npm scripts.

The concurrency guard now offers `--queue` only to a launch whose npm script
runs `run-vitest.js`; a plain-vitest script is told to wait instead.
