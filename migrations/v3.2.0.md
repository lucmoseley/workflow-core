# v3.2.0

## What changed

Breaking, action required: a checker opt-out marker takes a pointer, never
prose (#5540). Each `<name>-exempt:` marker (`arbiter-literal`,
`bare-citation`, `citation`, `claude-route`, `cli-args`, `gh-route`,
`git-identity`, `isolation`, `jsonl-read`) passes a site only when a pointer
follows it: `#N`, `owner/repo#N`, `ADR-NNNN` or an RFC. A marker followed by
prose no longer passes, so a commit that touches its file is refused. The
comment-policy gate reads a pointer marker as code.

`check-test-env-writes.js` passes no `env-write-kept:` marker (#5566): a
test's direct `process.env` write is refused whatever sits beside it. Use
`vi.stubEnv`, or run the case in a child process given its own env.

The queue lander picks its tester by run length (#5524). `landingTester`
takes `auto`, the default: over the newest 20 whole runs, a median suite time
over 3 minutes tests on Actions, else, or under 5 runs, locally; an Actions
ask that never starts is tested locally. The upgrade writes
`.github/workflows/workflow-core-lander.yml` and
`.github/workflows/workflow-core-named-rerun.yml` where `landingTester` is
absent or `auto`, and removes them where it pins `local`. On a private repo
those runs draw on the account's Actions minutes.

The comment-policy gate judges a shipped file's header (#5627) and skips
files `.gitattributes` marks `linguist-vendored` or `linguist-generated`
(#5530).

`resolve-ticket.js` refuses a build close whose `**Values:**` line holds an
untraced value, a guess or an estimate not tagged `delegated — <why>` or
`house: #N` (#5647).

The card rules in the shipped rule text, `rule:roadmap-gating`'s card branch
and the card-title and card-close rules, apply only where the `roadmap`
module is on (#5405).
