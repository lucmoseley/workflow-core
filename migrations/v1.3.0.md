# v1.3.0

## What changed

`.claude/workflow-core.md` now spells every command it names — the session
arbiter, `rule-text.sh`, `bg-run.sh`, `register-doc.js` and the doc-map
generator — at the plugin root, and `upgrade` re-renders it on every run, so
this walk re-points it and keeps `init`'s provenance block (workflow-core#654, workflow-core#662).

`scripts/lib/helper-surface.json` gains a `commands` list: each core script an
adopter may run by argv, with its promised positionals, flags and exit codes
(workflow-core#655, workflow-core#663). A command it does not list carries no promise.
