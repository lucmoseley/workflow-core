# v1.1.20

## What changed

`inject-recurrence-checks.sh` is renamed `inject-founder-wording.sh`, since it
now carries two patterns. Besides the recurrence checks, it hands a session the
`/wait-what` re-pitch whenever the founder's prompt asks for a simpler re-pitch
of the last reply — "explain it simpler", "you've lost me", "what do you need
from me?". The text is the skill's own body, read from the plugin install.

Listing the new name under `disabled` in `.claude/workflow-core.json` switches
both patterns off. A host listing the old name there loses that opt-out.

## Ruling

workflow-core#628, the spec. workflow-core#639 renamed the hook; workflow-core#642 added the re-pitch pattern.
