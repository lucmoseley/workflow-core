# v1.1.9

## What changed

`settingsKeys()` now writes `"autoMemoryEnabled": false` into an adopter's
`.claude/settings.json`, alongside the `env`, `permissions.deny`,
`autoCompactWindow` and `outputStyle` keys it already wrote. That turns off
Claude Code's self-written memory store, the recall that reads it and the index
auto-load, together.

It also writes `"worktree": {"bgIsolation": "none"}`, so a background session in
your repo edits the checkout directly instead of being made to isolate into a
git worktree first.

## Ruling

#192. The core has run with auto-memory off since `mantahostels#642`, on the
grounds that the store is unversioned and machine-local while every other
durable claim in a workflow-core repo is an authored document or an issue —
which is the case you are weighing if you take Manual step 2. The key cannot
ride in the plugin's own settings file, which supports `agent` and
`subagentStatusLine` only and ignores the rest, so the bootstrap is the only
route to an adopter.

#193 for the isolation key. The tool that performs the isolation is not offered
to a background session at all, so with isolation on every file edit that
session makes fails — including the edit that would turn the setting off. The
core has run with it off since `02ab82f3` for that reason. Concurrent sessions
are held apart by the arbiter's file claims, which the plugin already gives you,
rather than by separate worktrees.

## Residue

```json
{"settingsKeys": true}
```

## Manual steps

- [notice] Set `worktree.bgIsolation` yourself already? The residue leaves it
      alone.
- [choice] Want auto-memory on in your repo? Set the key to `true` yourself.
      The residue leaves an existing value alone, so a later `upgrade` will
      not flip it back.
- [notice] A session already running keeps auto-memory until it restarts.

## Verify

Proves both keys are present and of the right type in the repo `upgrade` is run
against — not that they read `false` and `"none"`, which would fail the upgrade
of an adopter that took a Manual step above and strand its pin on this note.

```sh
node -e "const s=JSON.parse(require('node:fs').readFileSync('.claude/settings.json','utf8'));process.exit(typeof s.autoMemoryEnabled==='boolean'&&typeof s.worktree?.bgIsolation==='string'?0:1)"
```
