# v2.3.1

## What changed

The mutation hold now runs Stryker's vitest runner under vitest's forks pool,
with Stryker's `disableTypeChecks` rewrite off (#5180). A covering test that
calls `process.chdir()` or runs a file as an executable, or a vitest
`execArgv` heap flag, no longer fails its initial run as red tests.
