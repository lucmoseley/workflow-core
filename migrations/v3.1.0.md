# v3.1.0

## What changed

`scripts/lib/write-fd.js` now exports `writeTerminal`, which writes through
`writeFd` for a path only a person at a terminal reads (#5484).
`scripts/check-program-output.js` no longer honours a `console-kept: <why>`
comment: a program that calls `process.exit` and writes through `console`,
`process.stdout.write` or `process.stderr.write` is refused whatever comment
sits beside the write.
