# v3.1.0

## What changed

Breaking, action required: the comment policy (#5455, #5477, #5482). A comment
in code is refused unless it is one of the kinds `docs/comment-kinds.md` lists.
`docs/code-standards-base.md` links that list and no longer asks for a file
header, a decision comment, a fail-open comment, an exported name's comment,
a marker comment or a written reason beside a suppression.

A new `comments` module turns on a pre-commit gate,
`scripts/check-comment-policy.js`, that refuses a commit adding a comment of
no permitted kind, or a suppression of a rule off
`scripts/lib/style-only-rules.json`. It charges only what a commit adds.

These checkers no longer pass a site for a marker comment beside it:

- `check-test-spawn.js` refuses a node spawn of the program under test unless
  it runs through `keptSpawn("<reason>")` from `scripts/lib/kept-spawn.js`
  (#5483).
- `check-program-output.js` refuses `console` before `process.exit` whatever
  sits beside it. `scripts/lib/write-fd.js` now exports `writeTerminal` for a
  path only a person at a terminal reads (#5484).
- `check-clock-copies.js` refuses any `WFC_NOW` read outside
  `scripts/lib/clock.js` (#5485).
- `check-code-standards.js` keeps an export no scan sees consumed only by a
  `{module, name, caller}` row in `docs/export-callers.json` (#5486).
- `check-swallowed-errors.js` passes an `except` that raises, exits or calls
  `fail_open` from `scripts/lib/fail_open.py`, never one citing a ticket
  (#5487).
- `check-guard-registry.js` reads a wired script's IMPLICIT / JUSTIFIED /
  DEFEAT / TREE from `.claude/implicit-behaviours.json`, never from its header
  (#5489).

`scripts/lib/noop.js` and `ignoreFailure` / `orFallback` in
`scripts/lib/caught.js` replace an empty block's comment (#5488).
