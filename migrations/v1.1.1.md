# v1.1.1

## What changed

`upgrade`'s residue vocabulary gains `roadmapMajorPin`: where an adopter's
`.claude/workflow-core.json` carries the `roadmap` module but no
`roadmapMajorPin` key, it is backfilled from that adopter's own
`docs/reference-roadmap.html` version line (`v<major>.<minor> · updated …`).

## Ruling

workflow-core#70 (found closing workflow-core#54, the ticket that first seeded the key — but only for a
*fresh* `init-adopter.js` run).

## Residue

```json
{"roadmapMajorPin": true}
```

## Manual steps

- [notice] Already hand-added the key yourself before this note ran? Nothing
      to do — the residue leaves an existing `roadmapMajorPin` alone.

## Verify

Proves only that the config still parses — not that `roadmapMajorPin` was
set.

```sh
node -e "JSON.parse(require('node:fs').readFileSync('.claude/workflow-core.json','utf8'))"
```
