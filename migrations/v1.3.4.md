# v1.3.4

## What changed

The push guard hands `push-cadence` to every repo, and each other push rule
only to a repo that meets its premise (#742). `push-green-suite` needs the
`suites` module and a test command that runs `scripts/run-vitest.js`, or none
declared (#758); `ci-status-lag` needs a `schedule:` in
`.github/workflows/scheduled-checks.yml`; `vercel-build-on-push` needs
`"deploy": "vercel"` in `.claude/workflow-core.json`, a new key.

Pre-commit runs a declared `commands.test` and refuses the commit on a red,
unless `suites` is on and the command runs `scripts/run-vitest.js` (#740).
