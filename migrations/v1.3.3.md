# v1.3.3

## What changed

Every core hook now starts `#!/usr/bin/env sh` and runs under `set -e` (workflow-core#745),
so a gate that fails without an explicit `exit` refuses the commit instead of
printing its refusal and letting it land. That covers
`check-skill-body-size.js`'s BROKEN (exit 2) and any command in
`.husky/pre-commit.local` that fails without `|| exit`.
