# v3.2.1

## What changed

The always-loaded pool no longer counts the machine-file rules v3.1.0 folds
into `.claude/workflow-core.md` (workflow-core#5683): *Removal means gone*, *Leading
practice* and *Reports and paid data*. `check-context-budget.js`, the
pre-commit ratchet and `check-doc-map.js`'s trigger verdict each measure that
file without those sections, so a bump that brings them in no longer pushes
the pool over its 22.5 KB cap. Growth elsewhere in the file still counts, so
a pool already over cap commits a bump once that growth nets to zero or below.
The budget report prints the excluded bytes on a new `MACHINE-MIRRORED RULES`
row, and its `--json` output carries them as `mirrored`.
