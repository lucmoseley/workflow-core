# v1.3.10

## What changed

Reviews now read one shared code-standards base, shipped in the plugin at
`docs/code-standards-base.md` and read there in place: nothing is copied into
your repo, and a rule id such as §N4 now means the same rule in every repo
(#947, #967). Your own `docs/code-standards.md`, where you keep one, is now a
local file holding only your repo's choices, through four operations and no
others: add a local rule (ids `§L<kind><n>`, such as `§LX1`); switch off a
stack or house clause; except named paths from a base rule, with a reason and
a ticket; and add or override route rows and risk paths. A local file never
switches off a principle or changes a severity, and a local sentence that
contradicts the base outside its changes table is itself a finding. A repo
with no local file gets the base unchanged. All three review routes hand the
Standards axis whichever files exist and open its report naming whichever is
missing or unreadable (#965). The base's line pins resolve at the plugin
root. Your repo's own citation check still reads only your local file (#963).
The plugin no longer ships the core's own `docs/code-standards.md`.

The plugin now loads two mods in your sessions, both on by default.
`wfc-delivery` brings a report your session's own start produced into the
session while it runs, rather than at the next start; a release request
against a file the session holds at its next turn; and a CI verdict that
changes mid-session within about ten minutes. `wfc-liveness` names a stalled
subagent in the status line and a toast, and `/liveness` opens a pane listing
every subagent. Neither runs anything from your repo, and the session-start
replay is unchanged.

To turn either off for every seat in the repo, commit
`{"mods": {"wfc-delivery": false}}` (or `"wfc-liveness": false`) in
`.claude/workflow-core.json`. A missing key, or a mod missing from it, means
on. Turning one off leaves the other and every command hook running.

Each mod starts nothing below Claude Code 2.1.289, and says so once in the
debug log. Installed plugins' modules also wait on a server rollout flag,
`tengu_plugin_hooks_modules`; the debug log's
`installed plugins' hooks modules held <n>ms for the rollout flag` line shows
the hold. Where the flag is off, the expected behaviour is that neither mod
loads, the command hooks run as today and the session-start replay still
delivers reports at the next start. That is unmeasured: no seat with the flag
off has been run. A session started in a subfolder loads neither mod, as it
already loads none of the plugin's command hooks.

Founder-facing work must now sit on an open issue. The close guard and
`resolve-ticket.js` read a close's `**Outstanding:**` line as a grammar: the
bare word `none`, or `#N (what is left)` items, each citing an open issue other
than the one closing. A shape miss or a closed, missing or self-citing carrier
is refused; with GitHub unreachable, shape alone is judged, logged (#982,
#984). A `--comment` holding a `$` or backtick expansion cannot be read
before it runs, so the close guard allows that close unchecked and logs it;
`resolve-ticket.js --comment-file` is the judged route (#990). A
`takes:human` issue, on create or relabel, is refused without a
`**Close when:**` line, and `rule:founder-deliverable` says what counts as
founder-facing and how to file it at once (#983). The issue-create guard also
refuses an empty `**Outside Claude Code:**` line whose act sits on a later line
(#995). Every session-ceiling notice carries an inventory step (#985).

Every checker built on `lib/check.js` refuses a flag it never declared, as
BROKEN, exit 2, naming the flag; a spec's new `flags` lists its booleans. A
checker of your own that reads an undeclared flag now stops instead of running
with defaults (#938).

`animate` routes brand and illustrative motion to the design vault's
`design-round`, says its easing and duration tables are for UI only, and gives
hard rule 6 a no-catalogue branch: the brand sheet alone, said in the
ingredients line (#987). `design-round`'s brand-motion easing section does not
exist until lucmoseley/design-vault#68 lands, so until then the pointer reaches
the round method alone.

A background job with nothing new may point at the question round it already
posted, unless a guard sent that round back (#924). `rule:founder-handover`
tells a session to gate a dependent step inside the founder's paste (#923).
`docs/agents/guard-authoring.md` says how an adopter registers a rule of its
own (#925); `docs/agents/verification.md` says what headless scratch outside
`.claude/` is reported as (#922). The guard-fire counter and the lost-deny
census count the hooks the plugin registers, so an adopter's reports list its
guards (#940, #954). `upgrade` rewrites the plugin-provenance line on every
run, and `init` records this repo's own installed commit (#941, #955). A
narrowed `run-vitest.js` run selects a changed file's readers from the read
graph the tree renders now (#998). Two skills ship for the core's weekly retro,
`retro` and `retro-sweep`; with no `retro` key in your config nothing files a
retro issue (#959, #964, #969).

A session at its context ceiling now carries on and lets the automatic
compaction fire; nothing launches or points it at a successor any more (#1178,
#1199, #1200). `launch-successor.sh` and its session-start brief injector are
gone. Parking a ticket blocked on the founder or an outside party is
`park-blocked.sh <issue> takes:wayfinder|waiting:external "<why>"`, or `keep`
in place of the label for a founder errand already labelled `takes:human`
(#1020, #1222). The arbiter's `held` and own-dirt verbs and `--self-as` on the
Outstanding-line check go with it. The 200,000 notice and the 100-turn notice now say: finish the unit in
flight even if a compaction fires, start no new one, and end. Past 300,000 the
guard speaks once, as a tripwire: compaction did not fire, so check
`autoCompactWindow`, commit and end the turn. A notice also lists the
session's own background jobs still running, so it waits for them before it
ends (#1201). After every automatic compaction the session is told how many
times it has compacted (#1032, #1148).

A background job's `result:` or `needs input:` ending must now carry its
inventory: a `waits on you:` block directly above the status line, each item
on an open issue, or `waits on you: nothing`. A new Stop guard refuses a
missing, misshapen or mismatched inventory, a closed or missing carrier, and a
`needs input:` round posted on no cited issue or on one the session never
claimed, three blocks a session (#988, #1066). A `waits on you: nothing` after
a turn that handed the founder a draft to send, sign or check is refused once
(#989).

A `takes:human` issue must name an act only the founder can do, or list the
three methods an agent tried first. `file-issue.js`, the label check and the
Bash create and relabel guard all refuse one that does neither, and every
refusal names the founder's acts (#1092, #1095, #1097).

New Bash and Write guards. A `find` started at `/`, `-xdev` included, is
refused (#1006). A `grep` pattern Claude Code's bundled ugrep may reject is
warned, since a refused pattern exits 2 and reads as no match (#1021). A
`Write` over a `.claude/tmp/` file this session did not write is warned
(#1167). Scratch written straight into a background job's own `tmp/` folder is
now refused rather than warned; a subfolder of it is still only warned (#1030,
#1139). A command opened by a shell keyword (`{`, `!`, `if`, `then`, `do`,
`time`, `exec`) no longer hides itself from the guards (#1013). A shellcheck
command is now told of a changed-files route, `check-sh-changed.sh`, which the
rule text spells `npm run check:sh:changed`: a script `init` does not give
your `package.json` (#1015).

In a repo using the plugin, a bare `code-review` Skill call is refused and
names `workflow-core:code-review` (#1165). A push whose code has no code review behind it
is warned, once a session (#1163).

The question-round guard sends back every close rival question once, whatever
its `Checked:` or `Unmeasured:` line, and keeps doing so after the session has
spent its other blocks (#1061, #1098, #1100). It refuses asking the founder to
paste a credential, and the retro transcript reader redacts pasted tokens
(#1031). A `waiting:` is accepted while a forked Skill or a Bash call the
harness moved to the background at its timeout is still running (#1012,
#1166). Every
close-check decision is logged in the markers directory (#1101).

The repeat-call guard keeps one history per agent, so a subagent's first read
is not refused for its parent's (#1004). It signs each Read with the file's
state on disk, so a re-read after a rewrite passes, and now refuses an
unchanged file's third re-read rather than its fourth (#1058, #1075, #1090).
The poll guard no longer tells a subagent to end its turn, and sibling
subagents no longer share one wait allowance (#1169). The wide-read guard
warns once and no longer promises a long read arrives whole (#1029, #1034,
#1079).

The pre-commit stack refuses a commit that adds a `docs/research/*.md` no
concision pass has cut this session; run the `concision-pass` skill over the
file first (#1005). The ruff gate's refusal names `ruffExclude` in
`.claude/workflow-core.json` for code kept as a record (#1022). The registry
guard judges a registry only where your repo carries it, so you can commit
hooks, guards and checkers of your own (#1162). `commit-paths.js` names the
commit the session just made, not a neighbour's landed on top (#1161), and the
session rules now tell you to commit through it (#1172).

A session start now warns where your git hooks name a plugin version that is
deleted or differs from the installed one, which aborts every commit until
`upgrade` re-points them (#1168). The lost-deny census reports a guard lost at its timeout in your repo too (#1017).
`npm run status` names stale git locks, and one no longer blocks the arbiter's
cleanup (#1193), and warns on an open gate with no `check:` line (#1246).

`file-issue.js` refuses to file while a similar open title is unchecked
(#1073), answers `--help` (#1078), and no longer writes a second
`Standalone` line (#1027). `issue-body.js append-section` takes a multi-line
`--file` in one write and refuses a `## ` line in it (#1019). A session opened
on an issue labelled for a different command is warned at its first prompt
(#1164). The arbiter lets a session stop once it has recorded a debt on an
edit a gate will not let it commit (#1170). The scheduled reporters and
several scripts answer `--help` and refuse a mistyped flag instead of running
on (#1040, #1051, #1062).

Where you run the core's test runner: a queued run skips or leaves the queue
once its selection is empty (#1016, #1158); a bare `npm run test` leaves a live
neighbour's unpushed commits to that session's own green, and `push:check`
says whose each uncovered commit is (#1213, #1216); a narrowed run selects a
library's own unit test, not every reader of it (#1126); the stall-killer
spares a long test file still working and records each kill (#1149). The suite
cap no longer counts a test-list probe, or one run as three (#1127, #1180). A
whole-suite run wrapped in a shell `timeout` is refused (#1186), a `-t` filter
no longer passes as a named file (#1196), a queued re-run over a covered HEAD
is refused once (#1211), and `--queue` read through `2>&1` passes (#1007). A bare
`npm run test:changed` now tests only the session's own uncommitted files, in
the same overlay a bare `npm run test` reads, so a neighbour's half-written
file no longer enters it (#1217). The overlay also carries a file the
session's inline `python` or `node` program names, and the Bash-write guard
notes such files only where your `test` script names `run-vitest.js` (#1220,
#1245). The re-run guard judges cover on the session's own commits and
uncommitted work, so a neighbour's commit on top no longer waves a repeat
through (#810, #1218).

A new skill, `browser-ladder`, says which browser route to try next and what a
session may do in the founder's signed-in Chrome (#1085, #1092, #1099, #1141). `rescue-sessions` resumes a session
stranded on another plan here, and takeover finds a stuck session's transcript
across plans (#1145, #1146). Where `retro` is on, `/pick-next` launches
retro-sweep findings as `/triage` bundles of at most eight, and the sweep
searches before every filing and keeps the founder's waivers (#1073, #1105,
#1195, #1206, #1224).

After a chained command is refused by the auto-mode classifier,
`rule:founder-handover` tells the session to re-run the allow-listed command
alone (#1023). `rule:branch-publish` says how to push a tag created in the
same command (#1033). The scratch sweep judges age on a time `tar` cannot set
back, and keeps a dispatched agent's evidence under `agents/` for seven days
(#1003, #1009).
