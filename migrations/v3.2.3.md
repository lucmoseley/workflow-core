# v3.2.3

## What changed

The commit-time comment-policy gate reads the committed
`.claude/workflow-core.json`, so a line opening on a declared
`commentMarkers` marker now passes at pre-commit as it does under `--all`
(#5709).

Breaking for a new gate: a `Gated on:` line's `check:` segment is held to
more.

- On a route that runs the check, a reading that prints neither
  `met`/`unmet` nor an `<a> of <b>` count is refused (#5756); a raw
  `gh issue create` only warns.
- On every write route, a read of another checkout's `origin/` ref, through
  `git -C`, `cd`, `--git-dir` or `--work-tree`, is refused unless a fetch of
  that checkout precedes it (#5697, #5755). A read of the host's own
  `origin/` passes.

The gate sweep judges a gate at once when its reading turns from unmet to
met, past the 6-hour bound (#5696). A gate's condition naming another issue
is a wait-graph edge: `link-blocker.js` refuses, and `check-issue-cycles.js`
reports, a loop through one (#5698).

Breaking for a pip install: the guard refuses a package the repo's
requirements files or `pyproject.toml` do not declare where its newest PyPI
upload is over five years old (#5760), or PyPI marks it archived,
deprecated or quarantined (#5762). A declared package passes.

The wait-loop guard reads a load gate's exit inside a `{ … }` group, and a
load read inside nested quotes in a `bash -c` script, so it refuses more
hand-rolled waits on machine load (#5773, #5778, #5779).

`guard-automode-refusal.js` also runs at `SubagentStop`, so a subagent that
works around an auto-mode refusal is sent back (#5774). A question round
carrying a `Blocked:` line owes a `Recurrence:` line reporting a
closed-issue search for the same act; `guard-priced-options.js` refuses a
round with none,
one the session ran no search for, and one recommending the option its own
`Recurrence:` line names as repeating the hand-over (#5786).

`/code-review` fixes or declines a whole-spec review's corner or tidying
finding, and tickets one only where an exception leaves it unfixed (#5771).

The outcome review counts a bug against a fix only on a `**Caused by:**`
line naming the fix's sha, which `file-issue.js --caused-by <sha>` writes
at filing (#5782, #5777).

The refill loop has no no-progress pause: nothing stops it after three
no-act finishes, and no founder-notice issue is filed (#5767). A tick in
which a held checkout skips a gate judgement still reads the frontier and
launches what it finds (#5766).
Admission holds the type-check reserve only while a type-check is queued
or running (#5703), charges a launch's spare pair once (#5704), and charges
each repo's lander its own measured whole-run peak, or 1,929 MB under 10
measured runs (#5705). The queue-wait alarm counts each session's
overlapping waits once (#5740), and a live queue place whose start time
will not read is kept (#5742).

The mutation hold runs Stryker in its throwaway worktree, so a
`worktreeLinks` artefact a test reads is present (#5768, #5721); a
`worktreeLinks` entry written with a trailing slash links (#5769).

A JSONL row a crash prefixed with zero bytes is kept, and the zeroed record
counted as lost (#5765). Retained logs and pass-store shards age on their
own timeline, so a session whose clock runs ahead no longer prunes them
(#5785, #5787, #5789).

## Manual steps

- [act] Where a refill loop runs an older release across this bump, it
      reads the new control file as damaged and stops itself; run
      `node "$WFC_PLUGIN_ROOT"/scripts/refill-loop.js start`.
- [act] Close a refill panel started before the loop restarted on this
      release, which crashes on the new status output, and reopen it with
      `node "$WFC_PLUGIN_ROOT"/scripts/refill-panel-open.js <pid>`, the
      agents view's pid from `pgrep -a claude`.
- [notice] Rolling a checkout back past this release leaves a control file
      the older loop reads as damaged; run
      `node "$WFC_PLUGIN_ROOT"/scripts/refill-loop.js start` there.
- [notice] The stricter gate checks bind only a new or rewritten
      `Gated on:` line; an existing one is judged as before. A refusal
      names the `met:`/`unmet:` print or the fetch the check lacks.
- [notice] In fantasy-books, lucmoseley/workflow-core-tracker#5709's
      `"commentMarkers": ["@encodes"]` commits once this bump lands.
