# v2.3.0

## What changed

The helper surface now lists the rule-text helpers v2.0.1's note sent you to:
`rule_text` in `scripts/lib/rule-text.sh`, and `readRuleText` and
`readRuleTextOr` in `scripts/lib/rule-text.js`. Their names and call shapes now
change only in a major release (#4780).

The helper surface now lists `scripts/run-pytest.js`, the pytest runner
v2.0.1's note had you write into CI, with its `--full` flag. It now exits 0 or
1 only: every failing pytest exit code reads as 1, and pytest's own report
says which (#4779).

The vendored `animate` skill is pulled up to emilkowalski/skills' `715c1807`;
nothing is owed from you (#4803). It now treats Motion's `x`/`y`/`scale`/`rotate`
props as hardware accelerated from Motion 14.2, and asks for an upgrade or a
full `transform` string only on an older version.

Your pre-commit hook now refuses a commit that adds a `Caller:`, `Callers:` or
`Callers of …:` line to the header of a script under `scripts/` or a skill's
`scripts/`, through the newly shipped `check-hand-callers.js` (#4885). Before,
`check-code-standards.js` only warned of one. `Unbuilt caller: <caller> (#N)`
still passes.

A session's own `gh` issue-link write is now refused (#5086): a `gh api` POST
to an issue's `dependencies/blocked_by` or `sub_issues`, the GraphQL
`addSubIssue` or `addBlockedBy` mutation, or a `gh issue create`/`edit` link
flag. Link through `scripts/link-blocker.js <blocked> <blocker>`, new, or
`scripts/link-sub-issue.sh <parent> <child>`, which gains `--replace-parent`
to re-root a child that already has a parent. Both refuse a link that would
close a loop, exiting 3 with nothing written.

Model routing reads one file, `scripts/lib/model-routing.json` (#5033). Work
routed to Sonnet now runs on Haiku 5.5 at xhigh, and burn mode moves Opus work
to Fable 5.2 and leaves Haiku work on Haiku 5.5 (#4919, #5006). The weekly
allowance cap holds nothing back below 99%, up from 97% (#4941).
